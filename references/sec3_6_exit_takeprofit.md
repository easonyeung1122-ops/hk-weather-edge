### 3.6 平仓 / 止盈：判据是「可成交价 vs 你的公允概率」，不是 90% / 10%

**先纠正一处措辞**：在二元合约里**「止盈」与「止损」是同一个动作** —— 都是按当前 bid 平仓。
成本价不进公式（沉没成本）。所以全天只有一个问题：

> **现在能卖到的价（`--depth` 加权），比我算的公允概率高，还是低？**

高 → 卖（多卖一份多赚一份）；低 → 留。**与 90%、10%、与成本、与当前浮盈浮亏都无关。**

**但「≥90% 卖 / ≤10% 留」背后有一个真命题 —— 而且两半是同一个命题**：
- 「≥90% 该卖」= 断言市场在高端**高估**
- 「≤10% 该留」= 断言市场在低端**低估**
- 两者等价于「**市场的隐含分布太窄（过度自信）**」→ 必然**同真同伪，不可能只对一半**。
- 这正是 §2.5 的发现：9/12 市场给 33 档 5–8%，实际 ≈75%。市场确实太窄。

**问题在于 0.90 这个数字分不出两种方向相反的情形。** 用台账 11 条有首推价的腿模拟
「碰到 0.90 就按 0.90 平仓」：

| 结算日 | Δ（规则 − 实际） | 被规则砍掉的赢腿 | 规则救下的腿 |
|---|---:|---|---|
| 09-09 | **−$59.00** | NO31 | — |
| 09-11 | **−$19.07** | NO30 / NO31 / YES32 | — |
| 09-12 | **+$132.43** | — | NO33 |
| **合计** | **+$54.36** | | |

**规则的全部收益来自 1 条腿。** 因为它把两种情形混在一起：
- **峰已过 / 当日 max 已定**（09-09 NO31、09-11 三条腿）→ 那一刻 0.90 就是真实概率，
  卖 = 白送 9.7%（赢腿到结算必然经过 0.90）。三天里这种情形让它倒亏 $78。
- **还有升温窗口 + 落在抖动区**（09-12 NO33：14:00 距 33.0 仅 0.4、抖动项 75%）→ 0.90 是虚高，卖对。

→ **决定符号的不是「概率到了多少」，而是 `d`（已观测最高 → 下一整数线的距离）
和「今天还有没有未兑现的升温窗口」。**

**「跌到 10% 以下不止损，搏尾部」同理，而且更危险**：

| 腿 | 情形 | 结果 |
|---|---|---|
| 09-12 NO32 @0.36 | 13:50 判死后被砸便宜，15:30 全港冲 33 反转 | **+$142.22**（规则对） |
| 09-12 YES31 @0.28 | 便宜后继续归零（含 13:50 加仓 $54） | **−$69**（规则错） |
| 09-09 YES30 @0.19 | 0.370→0.060 一路补仓，台账已注明**「无单笔止损线」** | **−$155**，全书最大单笔亏损 |

**区分它们的不是「便宜」，是「方向」**：顺着当天已确立趋势做 NO 的腿被砸下去还能回来
（09-12 NO32）；逆趋势买某个具体档的 YES 腿被砸下去就是真死了（YES30 / YES31）。
与 §3.3「盈利集中在顺上升方向做 NO」是同一条。

**→ 可执行写法（四条）**
1. 平仓判据只有一个：**可成交价（`--depth` 加权）> 公允概率**。不涉及 90/10，不涉及成本价。
2. 让它触发的是 **`d` 与剩余升温窗口**，不是概率水平。d ≥ 0.8 且峰已过 → 高概率就是真实概率，别卖。
3. 「便宜所以留着」只在两件事同时成立时有效：① 腿的方向与当天已确立趋势一致；
   ② 有**量化**的 edge（正例：09-12 33YES @0.05 —— 市场 5–8% vs 抖动 75.2% → 20 倍；反例：09-09 YES30）。
4. 唯一与概率无关的减仓理由：**敞口占本金超 25–30%** → 那是风控，不是止盈。

**样本限制**：13 腿 / 3 个结算日，且 09-09 与 09-11 结算档相同；多数腿**没有盘中价记录**，
「是否曾被触发」只能对赢腿（必然经过 0.90）和已知的 NO33（0.93）判定。方向可信，数字不可当期望值。
**待办**：台账加 `peak_price` 列（记录该腿盘中最高可成交价），之后才能对所有腿自动回测退出规则。

**已经「确定赢」的腿不要卖：变现不是理由，流动性有没有去处才是** `[v0.16.22]`

2026-09-15 13:00 轮主张「卖 NO29 172 份 @≥0.995 换现金」。13:45 轮**撤销**。
日最高已 31.4 ≥ 30 → 29 档必然归零 → **NO29 是确定赢，结算收满 $1.000/份**。
卖出价 0.999 只回收 $171.8 → **净损 $0.2**，而换来的 $171.8 现金**没有去处**
（当日 Kelly 上限只有 $40，`单日累计 ≤ 本金 25–30%` 也未触顶）。

**判据（两条都要过才卖）：**
1. **现金必须有明确的、EV 为正的去处**，且该去处的容量 > 变现额；
2. **折扣必须小于该去处的 EV**（本例：折扣 0.1%，去处 EV +11%，勉强过；
   但去处容量 $40 ≪ 变现额 $171.8 → **第 1 条不过**）。

> 反例（该卖的情况）：本金已顶到 25–30% 上限，且新机会 EV 显著 > 0.1%。
> 正例（不该卖）：只是「想落袋」。**已锁定的盈利在结算前不打折。**
