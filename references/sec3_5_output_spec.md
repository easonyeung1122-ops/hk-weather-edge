### 3.5 输出规范（对用户输出建议时必须带上）

- **|EV| > 8% 才动手**——0.79 °C 的 RMSE 意味着概率本身有 ±5% 量级误差。脚本内部 `MIN_EDGE=0.08` 已硬编码。

- **每次更新预测必须输出「模型各温度档位公允概率表」** —— 即 `hk_edge.py` 输出的「公允P」列，**全部覆盖档位**（含 <1% 的尾档，不截断到正 EV 档），与「市场价」列并排。这是模型对当日分布的完整陈述，也是 edge 计算的起点；缺此表 = 输出不完整。

- **窗口外 / 不出手时仍须披露 edge>8% 交易 idea（新纪律，2026-09-17；当日二次修订：留档 Kelly）**：即便当前不在 10:30–12:00 执行窗口，或某腿未通过 §3.4 混合情景全正判据（故不给出手指令），**只要 `|EV| > 8%，必须在结论里列出该交易 idea**：`档位 + 方向(YES/NO) + 模型公允P + 市场价 + EV + Kelly金额 + 份数`，并标注 **「研究观察，非执行指令（窗口外 / 不推荐实盘）；含留档 Kelly 金额，用于回溯研究最优下注时点」**。`
  - 目的：edge 是模型产出，与「此刻该不该下单」是两个问题；窗口关闭只禁止**带执行措辞的指令**，不禁止**披露机会与留档量化**。`
  - 禁止：因「13:20 后硬禁区」「提前一天」「只播实况」而把 edge>8% 的腿整段删掉（此前做法作废）。`
  - **留档 Kelly 必给**：窗口外/不出手的研究观察，仍须按 35% Kelly 给出 `金额 + 份数`（§3.5 末段公式），标注「研究留档，非执行」。用途：积累各时点边缘 idea 的实际盈亏，回溯**哪个下注时点 edge 最稳、ROI 最高**（实证：09:00–10:29 ROI −57.5%，10:30–12:00 为正）。错位实时价用那一时点的盘口 mid。`
  - 仍禁：**执行措辞**——窗口外不得写「现在买 / 立即下单 / 挂单成交」；留档 Kelly 仅作记录，不构成下单指令。`
  - 内部一致性 edge（§3.4 配套）与单档硬上限 edge（本节省尾）即使窗口外也必须点名 —— 它们不依赖「我方更准」，是最稳的披露对象。
- **EV 必须用订单簿可执行价算**（见 §3.1），用最后成交价算出的 edge 是假的。
- **挂限价单做 maker**，别吃单，taker 费用会吃掉薄盘的 edge。
- **跨 2–3 个相邻档 ladder**，收割分布形状而不是猜单点。
- **只要判定有 edge（|EV| > 8%），就必须给出 Kelly 仓位建议**——不能只说"买 YES"就收尾。
  买 YES `f* = (p−m)/(1−m)`，买 NO `f* = (m−p)/m`，**实操一律 35% Kelly**
  （脚本常量 `KELLY_FRAC = 0.35`；满 Kelly 波动过大，且概率本身有 ±5% 量级误差）。
  用户未给本金时**默认按 1000 USDC 估算，并明确标注这是假设**。
  **输出必须是三件套：金额 + 建议份数 + 占本金百分比**——只给金额等于没给，下单界面填的是份数。
  份数 = 金额 ÷ 该档单价（买 YES 用市场价 `m`，买 NO 用 `1−m`）；最后用**订单簿可执行价**复核一遍。
- **头寸建议一律双单位：`$金额 / N 份 @价`**（Eason 2026-09-14 明确要求）。
  这条覆盖**全部**动作类型 —— 开仓、加仓、减仓、平仓、对冲、止盈，以及给用户的头寸点评。
  **禁止**只写金额，也**禁止**用相对量词代替份数（「减半」「加一点」「对冲约 $22.8」「合计 ≤$280」都算违规）。
  正例：`减半 → 卖 74 份 @≥0.28（约 $20.7）`｜`NO30 $150 / 227 份 @0.6615`｜
  `31 YES 对冲 97 份 / $22.8 @0.235（把 31 档派息从 $0 抬到 $97）`。
  理由：下单界面填的是份数；只给金额等于让用户自己反推，薄盘里还会因扫单价差 1 分而差出几十份。
- **深度不足 ≠ 不报仓位**（Eason 2026-09-10 明确要求）。
  **只要判定有 edge，就必须照常给出 Kelly 三件套 —— 不要因为 ask 侧只有几份就省略，
  更不要写"可选、很小"这种含糊话。** 用户可以挂 maker 限价单等着成交。
  深度只影响**执行方式**，不影响**该买多少**：
  - 深度足够 → 吃单（taker），按 ask 成交
  - 深度不足 → 报同样的份数，但改成「挂 XX 价限价等成交」，限价取 bid/ask 之间或略优于 bid
  - 需要另注明的只是「可能不会全额成交 / 需要等多久」，**不是把仓位数字藏起来**
  反例（勿再犯）：「YES33 @0.110–0.120，EV +22~33%，但 ask 深度只有 5 份」——这里缺的正是 151 份 / $18。
- **Kelly 是独立头寸口径，组合里已有同向腿时要打折**（经验系数）：
  与现有持仓在同一结算档重叠 → **打 7–8 折**；反向对冲腿 → **不打折**。
  独立 Kelly 会高估，因为没算相关性。例：已持 NO31 时再加 YES33（33 档重叠），151 份 → 取 120 份。
- **薄盘时仍按 Kelly 报数**，只在括号里注明「ask 深度 N 份，建议挂限价」。
- **别碰 $0.05 以下的档**——EV 看着几百个百分点，但没有挂单，是流动性幻觉。
- **报浮盈必须同时报可成交量**（2026-09-10 实测）。薄盘里「浮盈 +20%」常常只能兑现 20 份：
  32 YES 曾 bid 0.260 而两侧深度都只有 **20 份**，150 份的仓位大部分平不掉。
  **浮盈是可报价，可成交量才是可兑现** —— 这两个数必须成对给出，否则等于误导。
- **EV 很负 = 止盈信号，必须主动提醒**。某方向「现在买入」的 EV ≤ `--exit-ev`（默认 **−15%**）时，
  脚本会在该档打 `⚠持YES止盈-XX%` / `⚠持NO止盈-XX%`；含义不是"该反向开仓"，而是
  **市价已明显高于公允值，还拿着这个方向的人应该平仓，而不是持有到期**。
  用户给了 `--hold` 时，持仓检查里会直接标「⚠ 止盈（现价高出公允 XX%）」并给出浮盈。
  每次复跑发现用户的已用头寸触发这个信号，**必须在结论里点名提醒**。
  ⚠ **但公允值本身在近边界处不可信**（v0.15.4）：未经 σ_flicker 覆盖的网格公允值会在
  「押封顶」那一侧给出「持有观察」的假信号 —— 9/12 14:00 的 NO33（d=0.4）就是这么被留到归零的。
- **单档概率有硬上限，用它可以做不依赖 mu 的止盈判断**（2026-09-10 实测，最强的一条）。
  1 °C 宽的档位，概率上限 = `2Φ(0.5/sd) − 1`，在 **mu 恰好落在档位中点** 时取到。
  sd 0.89（本模型典型值）→ 上限 **43%**；sd 0.76 → 49%。
  → **只要某档 YES 的 bid 超过这个上限，无论真实 mu 是多少，该价都必然高估，无条件卖出。**
  实测 9/10：32 YES bid 一度到 **0.46–0.48 > 43% 硬顶**。靠锚点吵不出结论时，硬上限直接给出答案 —— 卖。
  用前先确认当日 sd（`--date` 输出的「残差sd」）。
- **实况已逼近档位边界时，不要逆着 ≥90% 的市场价下注**（2026-09-11 实证）。
  判别只用一个数：**当前已观测最高 距下一个整数档的距离**。
  - **< 0.3 °C 且时间 ≤ 15:30** → 市场定价优先，模型只作参考；宁可空仓，不反向下注。
  - **≥ 0.6 °C** → 模型可以领先市场，按正常 edge 流程走。
  9/11 的 NO32 @0.040 就是踩了这条：13:30 距 32.0 只剩 0.2 °C，按分位表的 25% 反着市场做，20 分钟后被证伪。
  **判别钩子（两问，缺一不可）**：
  1. **离下一个整数档还有几度？** ≥ 0.6 °C 才有下注空间；< 0.3 °C 直接跟随市场。
  2. **网格的日变化曲线见顶了没有？** 见顶后当日不再有升温空间，无论距离多远都不下注。
- **边界日的赔率结构要看清**：当某档被市场定到 >95%，其余档的价格会被挤到 0.002–0.04 这种「看似百倍赔率」的位置。
  这些价位的名义 EV 动辄几千个百分点，但**深度与真实性都不可靠**（31 档 0.003、NO32 0.040 皆属此类）。
  按 Kelly 报数、注明深度，但**不要把它们当主仓**。
- **止盈对比必须用「总财富」口径，不能拿剩余成本比剩余期望**（2026-09-10 实测踩坑）。
  判断「卖不卖」时的正确式子：
  `卖出所得现金 + 剩余头寸的期望派息`  vs  `原头寸的期望派息`（同一成本基准下比较）。
  错误做法是把已卖出部分的成本从分母里剔掉、却又忘了把卖出所得加回来 —— 这会得出「卖光反而更差」的反向结论。
  实测 9/10：按错误口径算「留 29 份 YES32」是 −1%、「全卖」是 −9%；
  按正确口径重算是 **−3.9%(冷) / +4.9%(中) / +23.7%(暖) 全卖都占优**。
  结论：**只要卖出价 > 公允价，多卖一份就多赚一份，永远不要为了"留点敞口"而少卖**。
- **记录每笔「你的概率 vs 市场价 vs 结果」**，攒够 30 笔回头校准自己的命中率。
- **输出纪律：结论末尾必须给「下次刷新时间」**（见 §1.3）。
