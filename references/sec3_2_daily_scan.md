### 3.2 每日扫描与当日必做的三件事

```bash
# 1) 未来 7 天各档公允概率
py -3 scripts/hk_edge.py

# 2) 指定日期 + 喂入市场价 + 本金，输出 EV 与 35% Kelly 下注额
py -3 scripts/hk_edge.py --date 2026-09-09 --bankroll 500 \
  --market "29:0.12,30:0.30,31:0.42,32:0.11,33:0.03"

# 3) 模型与官方预报分歧时，按自己的判断手动加权点估计
py -3 scripts/hk_edge.py --date 2026-09-07 --mu 31.82 --market "31:0.37,32:0.51"

# 4) 当日：截断下限 + 覆盖点估计 + 收窄不确定性（三件套，日内必用）
py -3 scripts/hk_edge.py --date 2026-09-07 --observed-max 30.0 --mu 30.15 --sigma 0.5 \
  --market "30:0.71,31:0.235"

# 5) 同时产出 HTML 报告到 scripts/edge_report.html
py -3 scripts/hk_edge.py --html

# 6) 检查已用头寸：浮盈 + 该不该止盈（:N 表示持有 NO，默认 YES）
py -3 scripts/hk_edge.py --date 2026-09-08 --bankroll 1400 \
  --market "30:0.015,31:0.145,32:0.415,33:0.380,34:0.065,35:0.006" \
  --hold "34:0.065:200,33:0.56:70:N"
```

输出里每档给出：公允 P、市场价、动作、EV、**35% Kelly 的金额与建议份数**、**止盈警告 ⚠**、分布条。
底部固定提示一句"众数档仅 xx%——别把点预报当概率"，这是给持有仓位时的心理锚。

**当日（提前 0 天）必须做的三件事**

日最高温具有**单调性**：已经实测到的最高值就是当日峰值的硬下限，不可能被抹掉。

1. **截断下限**：`--observed-max <今日已实测最高>`。省略时脚本会自动从 `intraday_log.json` 读取。
   没有这一步，脚本会把大量概率质量放在物理上不可能的低档位上（实测曾出现把 43% 放在已实测最高温以下），
   **写进 `decision_log.csv` 会污染复盘数据集**。
2. **覆盖点估计**：`--mu`。午后一旦发生对流，NWP 的日最高值会失真，
   `--observed-max` 只修下限、不修均值。
3. **收窄不确定性**：`--sigma`。默认分布宽度是「提前一天」的（残差 sd + 集合距平 ≈ 0.96 °C），
   日内剩余不确定性小得多（实测：同一时刻算 31 档给出 32%，物理上只有 ~3%）。
   `--sigma` 表示**剩余总不确定性**，给出后不再叠加集合距平，直接用 `N(mu, sigma)`。
   典型取值：午后可观测时段 0.3–0.5，峰值窗口刚过 0.2–0.3。

传入 `--market` 时会自动把 `日期/档位/公允P/市场价/edge` 追加写到 `scripts/data/decision_log.csv`
——**结算后回来填实际档位做复盘**，这是长期唯一别人拿不走的 edge。

⚠ **每次出建议前都必须用 `--market "33:0.998"` 跑一次 `hk_edge.py`**（不是只跑 `market_prices`），
否则当天最关键的决策时点在复盘里就是黑的。
9/12 的 `decision_log.csv` 只有 3 个当日时点（09:18 / 09:19 / 10:11），**午后 0 条** ——
而当天最贵的几笔（13:50、14:10、15:30）全在午后，于是无法打分。
